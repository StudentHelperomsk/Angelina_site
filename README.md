# [Название проекта]

Информационный сайт проекта адаптивного спортивного топа для женщин после мастэктомии.

## Локальный запуск

Сайт не требует сборки или установки зависимостей. Откройте `index.html` в браузере либо запустите любой локальный статический сервер.

## Что заменить перед публикацией

- `[Название проекта]` и букву-заглушку в знаке;
- две карточки-заглушки официальными логотипами ФСИ и Платформы;
- кнопки документов ссылками на PDF бизнес-плана и отчёта;
- заглушки телефона и социальных сетей;
- при необходимости изображения продукта на реальные фотографии.

Изображения `adaptive-top-hero.webp` и `adaptive-top-detail.webp` сгенерированы специально для макета и не являются фотографиями серийного изделия.
