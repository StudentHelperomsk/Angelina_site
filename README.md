# [Название проекта]

Информационный сайт проекта адаптивного спортивного топа для женщин после мастэктомии.

## Локальный запуск

Сайт не требует сборки или установки зависимостей. Откройте `index.html` в браузере либо запустите любой локальный статический сервер.

## Что заменить перед публикацией

- `[Название проекта]` в заголовке, шапке и подвале;
- при необходимости заменить официальные логотипы ФСИ и Платформы на новые версии;
- кнопки документов ссылками на PDF бизнес-плана и отчёта;
- заглушки телефона и социальных сетей;
- при необходимости скорректировать подписи к фотографиям продукта.

На сайте используются фотографии прототипов, деталей конструкции и лекал, предоставленные командой проекта.

Финальный плоский знак хранится в `assets/images/brand-mark.svg`; базовая палитра сайта — графитовая, молочная и синяя в цвет прототипа.
